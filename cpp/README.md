# Лабораторная работа №3 — C++: умные указатели

Проект демонстрирует композицию, агрегацию и управление временем жизни объектов с помощью `std::unique_ptr`, `std::shared_ptr`, `std::weak_ptr`. Основа — классы `Hero`, `Enemy`, `Inventory` из ЛР №2. Предметная область и проверки сохранены.

## Таблица владения (по исходной ЛР №2)

| Где был указатель | На что указывает | Кто владеет | Замена | Почему |
|---|---|---|---|---|
| `Hero::m_enemy` (`Enemy*`) | Текущий противник | Внешний код (`main`) | `std::weak_ptr<Enemy>` | Герой наблюдает за противником и не должен продлевать его жизнь. Перед атакой вызывается `lock()`. |
| `main::dynamicHero` (`Hero*`) | Динамический герой | `main` / текущий владелец | `std::unique_ptr<Hero>` | Один владелец, автоматическое уничтожение; возможен `std::move`. |
| `main::inventories` (`Inventory*`) | Динамический массив инвентарей | `main` | `std::unique_ptr<Inventory[]>` | Один владелец массива, автоматическое уничтожение всех элементов. |
| `main::enemyPointers` (`Enemy**`) | Массив из указателей на трёх врагов | `main` (владеет и массивом, и каждым врагом) | `std::array<std::unique_ptr<Enemy>, 3>` | Каждый враг имеет одного владельца, контейнер фиксированного размера сам управляет своими элементами. |
| `main::enemyPointers[i]` (`Enemy*`) | Отдельный динамический враг | Соответствующий элемент массива | `std::unique_ptr<Enemy>` | Владелец у каждого отдельного врага один. |

## Исходные классы

- `Hero` — здоровье, атака, лечение, монеты; содержит `Inventory` по значению и невладеющий `weak_ptr<Enemy>`.
- `Enemy` — здоровье, атака, получение урона и проверка состояния.
- `Inventory` — максимум пять предметов и один талисман.

## Демонстрации в `main.cpp`

1. Композиция и агрегация: герой уничтожается вместе со своим инвентарём, но противник остаётся жив.
2. Статический противник: уничтожается в конце программы.
3. `unique_ptr`: владение героем передаётся через `std::move`, исходный указатель становится пустым, уничтожение происходит при выходе из блока.
4. Обычный массив противников: уничтожение при выходе из блока.
5. `unique_ptr<Inventory[]>`: динамический массив из трёх инвентарей, автоматическое уничтожение.
6. Массив из `unique_ptr<Enemy>`: автоматическое уничтожение каждого врага.
7. `shared_ptr`: счётчик владельцев `1 - 2 - 1`, уничтожение после последнего владельца.
8. `weak_ptr`: `lock()` работает до удаления последнего владельца; после `reset()` возвращает пустой указатель; `Hero::AttackEnemy()` корректно обрабатывает отсутствие врага.

Во всех этих примерах нет ручных `new`, `delete`, `delete[]`. Деструкторы выводят сообщения и показывают момент уничтожения объектов.

## Сборка и запуск из командной строки


**Windows (Developer PowerShell для Visual Studio / MSVC):**

```powershell
cl /std:c++17 /EHsc /utf-8 /I include src\main.cpp src\Hero.cpp src\Enemy.cpp src\Inventory.cpp /Fe:dungeon.exe
.\dungeon.exe
```

**GCC/MinGW:**

```powershell
g++ -std=c++17 -Wall -Wextra -Iinclude src/main.cpp src/Hero.cpp src/Enemy.cpp src/Inventory.cpp -o dungeon.exe
.\dungeon.exe
```
