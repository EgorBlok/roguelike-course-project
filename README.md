# Подземелье — курсовой проект по ООП

## Описание проекта

Проект представляет собой упрощённую пошаговую игру, в которой герой исследует подземелье, сражается с противниками, собирает предметы и использует талисманы.

На текущем этапе реализована демонстрационная часть проекта для лабораторной работы №3.

## Реализованные классы

### Hero — герой

Хранит здоровье, силу атаки, монеты, собственный инвентарь и указатель на текущего противника.

Основные возможности:
- Атака противника.
- Получение урона и восстановление здоровья.
- Получение монет.
- Взаимодействие с инвентарём.

### Enemy — противник

Хранит имя, здоровье и силу атаки.

Основные возможности:
- Получение урона.
- Атака.
- Проверка состояния (жив или побеждён).

### Inventory — инвентарь

Хранит до пяти расходуемых предметов и один активный талисман.

Основные возможности:
- Добавление и удаление предметов.
- Проверка вместимости.
- Экипировка и замена талисмана.

## Применение ООП

**Инкапсуляция:** поля классов закрыты, а доступ к состоянию осуществляется через методы.

**Композиция:** объект Hero содержит Inventory. Инвентарь автоматически создаётся и уничтожается вместе с героем.

**Агрегация:** герой хранит невладеющий указатель на Enemy. Противник создаётся независимо от героя и не уничтожается вместе с ним.

## Демонстрация

Файл `main.cpp` демонстрирует:

- Создание и уничтожение объектов.
- Композицию и агрегацию.
- Проверку ограничений предметной области.
- Автоматические, статические и динамические объекты.
- Обычные и динамические массивы.
- Массив указателей на динамические объекты.
- Использование `new`, `delete` и `delete[]`.

## Текущие ограничения

Проект пока не является полноценной игрой. Отсутствуют система комнат, магазин, полноценное управление ходами, автоматические эффекты талисманов и способности противников.

Эти возможности планируется реализовать на следующих этапах курсового проекта.
