# Roguelike Course Project

Курсовой проект по объектно-ориентированному программированию.

## Тема

Разработка игры в жанре Roguelike.

## Описание

Проект представляет собой пошаговую игру в жанре Roguelike.

Игрок исследует игровые локации, сражается с противниками,
получает предметы и улучшает своего персонажа.

В дальнейшем проект будет включать:

- систему игрока и противников;
- различные типы персонажей;
- предметы и экипировку;
- генерацию или набор игровых комнат;
- боевую систему;
- систему характеристик;
- инвентарь;
- развитие персонажа.

## Цель проекта

Практическое изучение принципов объектно-ориентированного
программирования:

- инкапсуляции;
- наследования;
- полиморфизма;
- абстракции;
- композиции;
- шаблонов / обобщений;
- делегирования.

## Реализации

Проект реализуется на двух языках программирования:

- C++;
- C#.
