# Лабораторная работа №4 - Java: наследование

## Структура

- `BaseCharacter.java` - абстрактный класс с общими характеристиками участников боя, `protected`-методами и `static`-счётчиком.
- `Hero.java` - `final`-наследник с собственным инвентарём, монетами и внешним противником.
- `Enemy.java` - наследник с реализацией `equals()` и `hashCode()`.
- `Inventory.java` - инвентарь с конструктором копирования.
- `Main.java` - только демонстрации лабораторной №4.

## Сборка и запуск из корня репозитория

```powershell
javac -encoding UTF-8 -d out java/src/*.java
java -cp out Main
